# African Photos and Videos - Premium Stock Photography & Videography

## Overview

A modern, premium website for authentic African stock photography and videography, optimized for SEO and designed to drive traffic to portfolio pages on Getty Images, Adobe Stock, Shutterstock, and Pond5.

## Customization

### Colors
Edit CSS variables in `style.css`:
```css
:root {
    --primary-color: #0066cc;
    --primary-dark: #0052a3;
    --text-color: #1a1a1a;
    /* ... more variables */
}
```

### Content
Update portfolio links in `index.html` with your actual contributor profiles.

### Images
Replace placeholder gradients with actual images using `background-image: url()`

6. Set up email for contact form
